# แผนที่บ้านนักเรียน

แสดงพิกัดบ้านนักเรียนบนแผนที่ · เลือกดูรายชั้น/รายคน · ระยะทางและเวลาเดินทางมาโรงเรียน (เดิน · จักรยานยนต์ · รถยนต์)

## หลักการ

- **ไม่กระทบข้อมูลเดิม**: ตารางใหม่ `GEO_HOME` (พิกัดบ้าน 1 แถว/คน ผูก `citizen_id`) และ `GEO_CONFIG` (พิกัดโรงเรียน · ความเร็วเฉลี่ย · ตัวเลือก) — [schema-geo.sql](../worker/schema-geo.sql) · ส่วนขยาย [schema-geo-002.sql](../worker/schema-geo-002.sql): `GEO_TRAVEL` (วิธีเดินทาง) · `GEO_LINK` (ลิงก์ผู้ปกครอง เก็บเฉพาะ hash) · `GEO_POINT` (จุดเสี่ยง) · คอลัมน์ใหม่ `GEO_HOME.road_*` (ระยะถนนจริงที่คำนวณเก็บไว้) · `STUDENTS` อ่านอย่างเดียว
- **ตามการเลื่อนชั้นอัตโนมัติ**: ชั้น/ห้องอ่านจาก `STUDENTS` ทุกครั้ง พิกัดผูกกับตัวนักเรียน → เลื่อนชั้นแล้วหมุดย้ายชั้นตาม · นักเรียน `status = inactive` (จบ/พ้นสภาพ) ไม่แสดง แต่พิกัดยังเก็บไว้
- **ข้อมูลอ่อนไหว (PDPA)**: ทุกคำสั่ง `geo.*` ต้องเข้าสู่ระบบด้วยบัญชีบุคลากร (ระบบผู้ใช้เดียวกับจัดตารางสอน — `tt-auth.js`)
  - `geo` ดูแผนที่: ผู้ดูแลระบบ · ผู้บริหาร · ฝ่ายวิชาการ · ครู
  - `geo_edit` บันทึก/ลบพิกัดบ้าน: ผู้ดูแลระบบ · ฝ่ายวิชาการ · ครู
  - `geo_admin` ตั้งพิกัดโรงเรียน/ความเร็วเฉลี่ย: ผู้ดูแลระบบ
  - นักเรียน/ผู้ปกครอง/บุคคลทั่วไป: ไม่มีสิทธิ์ (ยกเว้นหน้าลิงก์ส่งพิกัดด้านล่าง)
- **ครูเห็นเฉพาะชั้นตัวเอง** (ค่าเริ่มต้น `teacher_scope: homeroom`): บัญชีบทบาท "ครู" ได้เฉพาะนักเรียนในชั้นที่เป็นครูประจำชั้น — ดูจาก `TT_CLASS.homeroom_teacher_id` ของภาคเรียนปัจจุบัน (`current_year-current_semester`) เทียบ `TT_USER.teacher_id` · กรองที่ server ทุกคำสั่ง · บัญชีครูที่ยังไม่ผูกกับครู/ไม่ได้เป็นครูประจำชั้นจะไม่เห็นนักเรียน · ผู้ดูแลเปลี่ยนเป็น "ครูเห็นทั้งโรงเรียน" ได้ใน ⚙️ ตั้งค่าแผนที่
- **ลิงก์ผู้ปกครอง** (`home-pin.html?t=…`): token สุ่ม 256 บิต แสดงครั้งเดียว · DB เก็บเฉพาะ SHA-256 · ใช้ได้ 1 ครั้ง · หมดอายุ 14 วัน · สร้างใหม่ = ลิงก์เก่าที่ยังไม่ใช้ถูกยกเลิก · หน้าลิงก์เห็นแค่ชื่อจริง+ชั้น (ไม่มีนามสกุล/ที่อยู่/พิกัดเดิม) · พิกัดที่ส่งมาบันทึกเป็น `source: parent` (📨) ให้ครูกด "ตรวจ/ยืนยัน"
- `GEO_LINK` เป็นตารางลับ — ไม่อยู่ในสำรอง/กู้คืน/นำเข้า
- ส่งออก CSV มีระยะทาง/เวลา แต่**ไม่มีพิกัด**

## API (`worker/src/modules/geo.js`)

| action | สิทธิ์ | หน้าที่ |
|---|---|---|
| `geo.bootstrap` | geo | พิกัดโรงเรียน · ความเร็วเฉลี่ย · นักเรียนที่กำลังศึกษาทั้งหมด + พิกัดบ้าน |
| `geo.home` | geo | นักเรียน 1 คน + พิกัดบ้าน + พิกัดโรงเรียน |
| `geo.save_home` | geo_edit | บันทึกพิกัด (`lat`, `lng`, `accuracy`, `source: gps/map/manual`, `note`) |
| `geo.delete_home` | geo_edit | ลบพิกัด |
| `geo.save_travel` | geo_edit | `{citizen_id, mode}` วิธีเดินทาง (ว่าง = ล้าง) |
| `geo.save_road` | geo_edit | `{items:[{citizen_id, road_km, walk_min, car_min}]}` เก็บระยะถนนจริง (≤ 50/ครั้ง) |
| `geo.link_create` | geo_edit | `{citizen_ids, days?}` → `{expires_at, links:[{citizen_id, token}]}` |
| `geo.link_info` | สาธารณะ (token) | ชื่อจริง · ชั้น · พิกัดโรงเรียน |
| `geo.link_submit` | สาธารณะ (token) | `{token, lat, lng, accuracy?, travel?, note?}` ใช้ได้ครั้งเดียว |
| `geo.point_save` / `geo.point_delete` | geo_edit | จุดเสี่ยง `{point_id?, type, name, note?, lat, lng, radius_m}` |
| `geo.save_config` | geo_admin | `school:{lat,lng,name}` · `speeds:{walk,moto,car,road_factor}` · `options:{teacher_scope: homeroom/all, far_km}` |

ทุกคำสั่งที่ต้องเข้าสู่ระบบกรองตามขอบเขตครูประจำชั้น (`FORBIDDEN` ถ้าเป็นนักเรียนนอกชั้น)

## หน้าเว็บ

- `map.html` + `js/modules/student-map.js`: เลือกชั้น · ค้นหาชื่อ · หมุดสีตามชั้น (ขอบส้มประ = ผู้ปกครองส่งมา) · วงรัศมี 1/3/5 กม. + วงเกณฑ์บ้านไกล (แดง) · ชื่อบนหมุด · ⚠️ จุดเสี่ยง · 🔥 ความหนาแน่น (leaflet.heat) · 🏘️ กลุ่มบ้าน · สถิติ
  - กดหมุด: ข้อมูลนักเรียน/ผู้ปกครอง · วิธีเดินทาง · จุดเสี่ยงที่ผ่าน · ระยะ+เวลา · "ตามถนนจริง" (คำนวณแล้วเก็บไว้) · "นำทาง" · "แก้พิกัด" / "ตรวจ/ยืนยัน"
  - แท็บ **📋 รายชื่อ**: เลือกวิธีเดินทางในตาราง · ติ๊กเลือก → สร้างลิงก์ผู้ปกครอง · CSV
  - แท็บ **🚸 วิธีเดินทาง**: ตารางชั้น × วิธีเดินทาง + ร้อยละ · CSV
  - แท็บ **📏 บ้านไกล**: เกณฑ์ กม. (ผู้ดูแลตั้ง) · สรุปรายชั้น · CSV สำหรับขอค่าพาหนะ · ปุ่ม "คำนวณระยะตามถนนจริง" (ทีละคน เว้น ~1.5 วินาที · ยกเลิกได้)
  - แท็บ **🏘️ กลุ่มบ้าน / รถรับส่ง**: จัดกลุ่มบ้านที่ห่างกันไม่เกิน N เมตร · ชื่อกลุ่มจาก "หมู่ X" ในที่อยู่ · เลือกกลุ่ม → วางเส้นทางรถ (เรียงจุดใกล้สุดถัดไปจากโรงเรียน · ระยะ/เวลาประมาณ)
  - แท็บ **⚠️ จุดเสี่ยง**: เพิ่มโดยแตะบนแผนที่ · นักเรียนที่ต้องผ่าน = จุดอยู่ใกล้แนวเส้นตรงบ้าน–โรงเรียนภายในรัศมี (ประมาณ)
  - ลิงก์ผู้ปกครอง: คัดลอกทีละคน/ทั้งหมด (ส่งไลน์) · พิมพ์ QR (qrcode-generator 1.4.4)
- `home-pin.html` + `js/modules/home-pin.js`: หน้าผู้ปกครอง (ไม่ต้องเข้าสู่ระบบ) — GPS / แตะ-ลากหมุด · เลือกวิธีเดินทาง · จุดสังเกต · ส่งครั้งเดียว
- `students.html` โปรไฟล์นักเรียน → ปุ่ม **📍 พิกัดบ้าน** (ขอเข้าสู่ระบบถ้ายังไม่ได้เข้า)
- `js/geo.js` ใช้ร่วม: `GeoUtil` (Leaflet 1.9.4 lazy-load · แผนที่ OpenStreetMap / ภาพดาวเทียม Esri · ระยะ haversine · ประมาณเวลา · OSRM) และ `GeoPicker` (หน้าต่างปักหมุด: อ่าน GPS ของอุปกรณ์ + วงความแม่นยำ + เตือนเมื่อ > 50 ม. · ลากหมุด · แตะแผนที่ · วางพิกัด/ลิงก์ Google Maps · จุดสังเกต · เตือนเมื่อห่างโรงเรียน > 50 กม.)

## เวลาเดินทาง

- **ประมาณ** (คำนวณในเครื่อง ไม่ส่งข้อมูลออก): ระยะถนน ≈ ระยะเส้นตรง × `road_factor` (ค่าเริ่มต้น 1.3) · เวลา = ระยะ ÷ ความเร็วเฉลี่ย (เดิน 4 · จักรยานยนต์ 35 · รถยนต์ 40 กม./ชม. — ผู้ดูแลแก้ได้)
- **ตามถนนจริง** (กดปุ่มในหมุดเท่านั้น): OSRM ของ FOSSGIS (`routing.openstreetmap.de` — routed-foot / routed-car) ส่งเฉพาะพิกัด 2 จุด ไม่ส่งชื่อ · จักรยานยนต์ = ระยะเส้นทางรถ ÷ ความเร็วจักรยานยนต์
- GPS ต้องเปิดผ่าน HTTPS (GitHub Pages ใช้ได้) และผู้ใช้อนุญาตสิทธิ์ตำแหน่ง
