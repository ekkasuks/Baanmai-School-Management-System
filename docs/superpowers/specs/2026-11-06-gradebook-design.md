# วิชาการ › บันทึกคะแนน (Gradebook) — Design

อนุมัติโดยผู้ใช้ 2026-11-06 · สร้างทีละเฟส (ทดสอบ local ทุกเฟสก่อนขึ้นจริง)

## การเข้าใช้ — บัญชีผู้ใช้เต็มรูปแบบ (TT_USER / tt-auth.js)
- หน้าเข้าสู่ระบบแบบ "เลือกชื่อ + รหัสผ่าน" (`tt.login_choices` สาธารณะ: user_id + ชื่อที่แสดงของบุคลากรที่ใช้งานอยู่ · `tt.login` รับ `user_id` แทน `username` ได้) · ยังเข้าด้วยชื่อผู้ใช้ได้
- ผู้ดูแลสร้างบัญชีครูทั้งหมดจาก TT_TEACHER ของภาคปัจจุบัน (`tt.teacher_accounts` + `tt.user_create_teacher` ทีละคน — PBKDF2 ต่อคนใช้ CPU มาก ห้ามทำหลายคนในคำขอเดียว) · รหัสผ่านเริ่มต้นสุ่ม แสดงครั้งเดียวให้พิมพ์แจก
- TT_TEACHER เป็นรายภาค (คัดลอกภาค = teacher_id ใหม่) → `teacherForTerm(db, user, term)` หาแถวครูของภาคนั้นจาก teacher_id ตรง ๆ หรือ code / ชื่อ ที่ตรงกัน
- สิทธิ์ใหม่: `gb` (บันทึกวิชาที่ได้รับมอบหมาย) ครู/วิชาการ/ผู้ดูแล · `gb_admin` (แก้ได้ทุกวิชา ปลดล็อก) วิชาการ/ผู้ดูแล · `gb_view` (ดูภาพรวม) ผู้บริหาร/วิชาการ/ผู้ดูแล

## รายวิชา
- รายวิชา = วิชา × ชั้น × ภาค จาก `TT_ASSIGN` (term_id, class_id, subject_id → teacher_id) · course_id = `term:class_id:subject_id`
- รายชื่อนักเรียนอัตโนมัติจาก STUDENTS (active) ตามชั้น/ห้องของ TT_CLASS (ห้องว่าง/0 = 1) · เฟส 2 ถ่ายรายชื่อ ณ ภาคนั้นลง GB_ROSTER (แบบ ACAD_MULT_ROSTER)

## โครงสร้างคะแนน (เฟส 2–3)
- 4 ช่วง: ก่อนกลางภาค 30 · กลางภาค 20 · หลังกลางภาค 20 · ปลายภาค 30 (แก้ได้รายวิชา รวม 100)
- รายการงานในแต่ละช่วงไม่จำกัด · คะแนนช่วง = Σ ได้ / Σ เต็ม × น้ำหนักช่วง (ย่ออัตโนมัติ)
- เกรด: ≥80=4 · 75=3.5 · 70=3 · 65=2.5 · 60=2 · 55=1.5 · 50=1 · <50=0 (แก้ได้) · ผลพิเศษ ร / มส รายคน
- หักคะแนน 2 แบบ: (1) ส่งช้าในงาน — งานตั้ง % หัก, ติดป้าย ช้า/ไม่ส่ง/ยกเว้น (ยกเว้น = ไม่นับงานนั้น) (2) หักจากคะแนนรวมพร้อมวันที่+เหตุผล (ยกเลิก = void ไม่ลบ) · คะแนนรวมไม่ติดลบ
- ส่งผล = ล็อกรายวิชา · gb_admin ปลดล็อก · ภาคเก่าแก้ได้เฉพาะ gb_admin

## ตารางใหม่ (เฟส 2+) — ไม่แตะตารางเดิม, มีคอลัมน์ citizen_id → purge/แก้เลขครอบคลุมอัตโนมัติ
GB_COURSE (snapshot ชื่อวิชา/ชั้น/ครู, น้ำหนักช่วง, เกณฑ์เกรด, สถานะ) · GB_ROSTER · GB_ITEM (active=0 แทนการลบ) · GB_SCORE (`item_id:citizen_id`, score, flag) · GB_DEDUCT (voided_at) · ผลพิเศษเก็บใน GB_ROSTER.special
- PK ที่มี citizen_id ต้องเพิ่มใน `PK_REBUILD` ของ students.js

## แดชบอร์ด (เฟส 4)
- ครู: การกระจายเกรด, เฉลี่ย/ต่ำสุด/สูงสุด, นักเรียนเสี่ยง (<50 หรือค้างงาน), % บันทึกและค่าเฉลี่ยรายงาน, รายบุคคล
- วิชาการ/ผู้บริหาร: ตาราง ชั้น × วิชา (ความคืบหน้า/ค่าเฉลี่ย), การกระจายเกรดรายชั้น, ความคืบหน้ารายครู, นักเรียนเสี่ยงหลายวิชา, CSV

## เฟส
1. บัญชีครู (สร้างทั้งหมด + เลือกชื่อเข้าสู่ระบบ) + หน้า "วิชาของฉัน" + รายชื่อนักเรียนรายวิชา — ไม่มีตารางใหม่
2. GB_COURSE/ROSTER/ITEM/SCORE + ตั้งค่าวิชา + ตารางบันทึกคะแนน (คอม/มือถือ) — เสร็จ: `acad.gb_course_save` (น้ำหนักจำนวนเต็ม รวม 100 · ช่วงที่มีงานตั้ง 0 ไม่ได้), `gb_item_save` (เพิ่ม/แก้/กู้คืน · ลดคะแนนเต็มต่ำกว่าคะแนนที่มีไม่ได้), `gb_item_remove` (active 0), `gb_score_save` (≤200 ช่อง/คำขอ, 14 แถว/คำสั่ง) · รายชื่อ sync เฉพาะผู้แก้ไขได้ในภาคปัจจุบัน (ผู้ดูไม่เขียน) · ช่องว่างนับ 0 ในคะแนนรวม · หน้าเว็บบันทึกอัตโนมัติ (หน่วง 0.9 วิ)
3. หักคะแนน 2 แบบ + ตัดเกรด + ร/มส + ส่งผล/ล็อก
4. แดชบอร์ด + CSV
