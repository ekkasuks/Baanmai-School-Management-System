# วิชาการ › ท่องสูตรคูณ

บันทึกการท่องสูตรคูณแม่ 2–12 ของนักเรียนรายคน · ทดสอบทุกภาคเรียน ทุกปีการศึกษา · แดชบอร์ดสรุปผล

เมนูหน้าหลัก **วิชาการ** (`academic.html`) → **ท่องสูตรคูณ** (`multiplication.html`) · เพิ่มโมดูลวิชาการอื่นได้ที่ `ACAD_MENUS` ใน `academic.html`

## หลักการ

- **ไม่กระทบข้อมูลเดิม**: ตารางใหม่ [schema-academic.sql](../worker/schema-academic.sql) · `STUDENTS` / `SETTINGS` อ่านอย่างเดียว
  - `ACAD_MULT` ผลการท่อง 1 แถว/นักเรียน/แม่/ภาคเรียน (`rec_id = term:citizen_id:table_no`) · วันที่ท่องผ่าน · ผู้บันทึก
  - `ACAD_MULT_ROSTER` ชั้น/ห้องของนักเรียน ณ ภาคเรียนนั้น (`roster_id = term:citizen_id`)
- **ข้อมูลเดิมไม่หาย**
  - แยกตามภาคเรียน (`term = ปี-ภาค` จาก `current_year` / `current_semester` ในตั้งค่าระบบ) — ขึ้นภาคใหม่ = เริ่มบันทึกใหม่ ภาคเก่าเก็บไว้ครบ
  - ยกเลิกการเช็ค = `passed 0` (ไม่ลบแถว) + บันทึก `AUDIT_LOG` (`acad / MULT_UNCHECK` พร้อมวันที่เดิม)
  - เลื่อนชั้นแล้วสถิติภาคเก่ายังอยู่ที่ชั้นเดิม: ชั้นของภาคปัจจุบันซิงก์จาก `STUDENTS` ทุกครั้งที่เปิดหน้า แต่**หยุดซิงก์รายคนเมื่อนักเรียนมีผลการท่องในภาคนั้นแล้ว** และภาคที่ผ่านไปแล้วไม่ซิงก์อีก
  - อยู่ในไฟล์สำรองข้อมูล (ไม่ใช่ตารางลับ) · กู้คืนไฟล์สำรองเก่าที่ไม่มีตารางนี้จะไม่ลบผลการท่อง
- **ไม่ต้องเข้าสู่ระบบ** สำหรับภาคเรียนปัจจุบัน — ใครเปิดหน้าก็ดูและบันทึกได้ · ผู้บันทึกพิมพ์ชื่อตัวเองครั้งแรก (จำไว้ใน localStorage ของเครื่อง) · ถ้าเข้าสู่ระบบบุคลากรอยู่แล้วใช้ชื่อบัญชีแทน
  - ดูภาคเก่า / ทุกภาคเรียน / รายคน ได้โดยไม่ต้องเข้าสู่ระบบ
  - **แก้ภาคเรียนที่ผ่านมา** ต้องเข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์ `acad_admin` (ผู้ดูแลระบบ · ฝ่ายวิชาการ) — ปุ่ม "เข้าสู่ระบบ" ในแถบแจ้งเตือนภาคเก่า
  - หน้าเป็นสาธารณะ → API **ไม่ส่งเลขประจำตัวประชาชน**: ใช้ `sid` = HMAC-SHA256(`ADMIN_KEY`, citizen_id) 20 ตัวอักษร แทน · server แปลง sid กลับเองตอนบันทึก
  - ความเสี่ยงที่ยอมรับ: ใครมีลิงก์ก็เห็นชื่อ-ชั้นนักเรียน และเช็ค/ยกเลิกได้ — ยกเลิกไม่ลบแถวและมี `AUDIT_LOG` · บันทึกได้ครั้งละ ≤ 20 รายการ

## API (`worker/src/modules/academic.js`)

| action | สิทธิ์ | หน้าที่ |
|---|---|---|
| `acad.mult_bootstrap` | สาธารณะ | `{term?}` → รายชื่อ (sid · ชั้น ณ ภาคนั้น) + ผลที่ผ่าน · รายการภาคเรียน · `can_record` |
| `acad.mult_set` | สาธารณะ (ภาคปัจจุบัน) · acad_admin (ภาคเก่า) | `{term, sid, table_no, passed, date?, recorded_by}` (`recorded_by` บังคับถ้าไม่ได้เข้าสู่ระบบ) |
| `acad.mult_set_many` | เหมือนข้างบน | `{term, items:[…]}` ≤ 20 รายการ/ครั้ง |
| `acad.mult_summary` | สาธารณะ | ทุกภาค × ชั้น × ห้อง: จำนวนคน · ท่องครบ · ยังไม่ผ่านเลย · รวมแม่ที่ผ่าน |
| `acad.mult_student` | สาธารณะ | `{sid}` ประวัติทุกภาคเรียนของนักเรียน 1 คน |

## หน้าเว็บ (`multiplication.html` + `js/modules/multiplication.js`)

- แถบบน: เลือกภาคเรียน (ค่าเริ่มต้น = ภาคปัจจุบัน) · เลือกชั้น · "รวมอนุบาล" (ค่าเริ่มต้นซ่อนชั้น อ.)
- **✅ บันทึก**: ตารางนักเรียน × แม่ 2–12 · แตะช่อง = ท่องได้ (บันทึกทันที) · แตะซ้ำ = ยกเลิก (ถามยืนยัน) · แตะชื่อ = **โหมดท่องทีละคน** ปุ่มใหญ่ · ระบุวันที่ท่อง (ย้อนหลังได้ ห้ามอนาคต) · "ท่องได้ทุกแม่ที่เหลือ" · คนก่อน/ถัดไป
- **📊 แดชบอร์ด**: นักเรียน · ท่องครบ 11 แม่ · เฉลี่ยแม่/คน · ยังไม่ผ่านเลย · ร้อยละรายแม่ · การกระจายจำนวนแม่ต่อคน · ตารางชั้น × แม่ (ทุกชั้น) · รายชื่อที่ยังไม่ครบพร้อมแม่ที่ขาด · CSV รายคน (มีวันที่ท่องผ่าน)
- **📈 ทุกภาคเรียน**: ร้อยละท่องครบรายชั้นทุกภาคเรียน + ทั้งโรงเรียน · CSV
- **👤 รายคน**: ภาคเรียน (ชั้น ณ ภาคนั้น) × แม่ พร้อมวันที่และผู้บันทึก
