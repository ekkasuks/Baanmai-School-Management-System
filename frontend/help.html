📋 เช็คการมาเรียน

แท็บ: สรุปรายวัน · เช็คชื่อ · ภาพรวม · ประวัติ

เช็คชื่อรายชั้น

  1. ไปแท็บ เช็คชื่อ → เลือก วันที่ และ ชั้นเรียน
  2. รายชื่อนักเรียนจะขึ้นมา โดยตั้งค่าเริ่มต้นเป็น “มา” ทุกคน
  3. แตะปุ่มสถานะของคนที่ไม่มา เพื่อเปลี่ยนเป็น ขาด / ลา / สาย
  4. ใส่ชื่อผู้บันทึก แล้วกด บันทึกการเช็คชื่อ
💡 ปุ่ม “ตั้งทุกคนเป็นมา” ช่วยรีเซ็ตทั้งห้องกลับเป็นมาได้เร็ว · เช็คชื่อซ้ำวันเดิม = อัปเดต ไม่เพิ่มซ้ำ

ดูสรุป / ประวัติ

  • สรุปรายวัน — ตารางมา/ขาด/ลา/สาย แยกชั้น พร้อม Export PDF
  • ภาพรวม — กราฟ + รายชื่อที่ไม่มาของวันที่เลือก
  • ประวัติ — ค้นย้อนหลังตามช่วงวันที่/ชั้น/สถานะ
🐷 ธนาคารโรงเรียน

แท็บ: ภาพรวม · ฝาก/ถอน · ประวัติ · สมุดบัญชี · นิสัยออม

ฝาก / ถอนเงิน

  1. ไปแท็บ ฝาก/ถอน → เลือกชั้นเรียน → แตะชื่อนักเรียน
  2. กรอกจำนวนเงินและผู้บันทึก
  3. กด ฝากเงิน (สีเขียว) หรือ ถอนเงิน (สีส้ม)
  4. กด พิมพ์สลิป เพื่อออกสลิป PDF ได้ทันที
⚠️ ถอนเกินยอดคงเหลือไม่ได้ — ระบบจะแจ้งเตือนและไม่บันทึก

อื่น ๆ

  • สมุดบัญชี — พิมพ์ชื่อ/รหัสค้นหา → ดูรายการเข้า-ออกทั้งหมด + Export PDF
  • นิสัยออม — จัดอันดับความถี่การฝากรายเดือน (ส่งเสริมการออม)
🎓 ทุนการศึกษา

เลือกปีการศึกษาด้านบน · แท็บ: บันทึก · ภาพรวม · ประวัติ

บันทึกการรับทุน

  1. เลือก ปีการศึกษา ด้านบน
  2. แท็บ บันทึก → เลือกชั้น → แตะชื่อนักเรียน
  3. กรอก ชื่อทุน, จำนวนเงิน, วันที่ได้รับ แล้วกด บันทึกทุน
  4. บันทึกได้หลายทุนต่อคน · ลบรายการได้จากตารางด้านล่าง

ดูสรุป

  • ภาพรวม — เงินทุนรวม, สรุปรายชั้น, นักเรียนที่ได้รับทุนสูงสุด
  • ยอดทุนของนักเรียนแต่ละคนจะไปแสดงในหน้า ข้อมูลนักเรียน ด้วย
⭐ พฤติกรรมนักเรียน

เลือกเดือนด้านบน · แท็บ: ภาพรวม · บันทึก · อันดับ · ประวัติ · รายการพฤติกรรม

หลักการให้คะแนน

  • ทุกคนเริ่มต้น 20 คะแนน ทุกเดือน (ขึ้นเดือนใหม่รีเซ็ตเป็น 20 อัตโนมัติ)
  • คะแนนเพิ่ม/ลด ตามรายการที่บันทึก

บันทึกพฤติกรรม

  1. แท็บ บันทึก → เลือกชั้น → แตะชื่อนักเรียน
  2. แตะปุ่มรายการพฤติกรรม (สีเขียว = เพิ่ม, สีส้ม = หัก) — คะแนนอัปเดตทันที
💡 ตั้งรายการพฤติกรรมเองได้ที่แท็บ รายการพฤติกรรม (เพิ่ม/หัก, กำหนดคะแนน) · แท็บ อันดับ Export PDF ได้
⚜️ กิจกรรมลูกเสือ

เลือกปีด้านบน · แท็บ: แดชบอร์ด · สร้างกิจกรรม · บันทึกคะแนน · หมู่ลูกเสือ

ลำดับการใช้งานครั้งแรก

  1. สร้างหมู่ลูกเสือ (แท็บ หมู่ลูกเสือ) → พิมพ์ชื่อหมู่ → บันทึกหมู่
  2. แตะการ์ดหมู่ → กด เพิ่มสมาชิก → เลือกนักเรียนจากรายชื่อเข้าหมู่
  3. ที่ท้ายชื่อสมาชิก กดปุ่ม นายหมู่ / รองนายหมู่ เพื่อกำหนดตำแหน่ง
  4. สร้างกิจกรรม → ใส่ชื่อกิจกรรม, งานที่มอบหมาย, คะแนนเต็ม
  5. บันทึกคะแนน → เลือกกิจกรรม → กรอกคะแนนของแต่ละหมู่
💡 ให้คะแนน “ต่อหมู่” — สมาชิกทุกคนในหมู่ได้คะแนนเท่ากันอัตโนมัติ · นายหมู่จะขึ้นชื่อแรก, รองนายหมู่ขึ้นชื่อสุดท้าย · แดชบอร์ด แสดงอันดับคะแนนรวม + ชื่อนายหมู่ในวงเล็บ
🥛 นมโรงเรียน

แนวคิด

  • นักเรียนได้รับนมคนละ 1 กล่อง/วัน
  • วันที่ ขาด/ลา (จากการเช็คชื่อ) = ยังไม่ได้รับนม → ค้างสะสม
  • (มาสาย = ถือว่ามาโรงเรียน ได้รับนมตามปกติ)

จ่ายนมค้าง

  1. หน้าแรกแสดงจำนวนนักเรียนและกล่องนมที่ค้าง แยกตามชั้น
  2. เมื่อจ่ายนมค้างให้นักเรียนแล้ว กด “ได้รับนมแล้ว” เพื่อเคลียร์ยอดของคนนั้น
⚠️ ปุ่ม “ล้างทั้งโรงเรียน” จะถือว่านมค้างก่อนวันนี้จัดการหมดแล้ว — ใช้เมื่อเริ่มนับใหม่เท่านั้น
🩺 ตรวจสุขภาพ

แท็บ: บันทึกผลตรวจ · ภาพรวม · ประวัติ

บันทึกผลตรวจรายชั้น

  1. เลือกวันที่ตรวจ และชั้นเรียน
  2. แต่ละคนมี 5 ช่อง: ผม · เล็บ · แก้วน้ำ · แปรงสีฟัน · ยาสีฟัน — ค่าเริ่มต้น “ผ่าน” (สีเขียว)
  3. แตะช่องที่ ไม่ผ่าน ให้เป็นสีแดง แล้วกด บันทึกผลตรวจทั้งห้อง
💡 “ตั้งทุกคนเป็นผ่าน” ช่วยกรอกเร็ว · ภาพรวมมีกราฟรายข้อ + รายชื่อที่ไม่ผ่าน + Export PDF
📏 การเจริญเติบโต (BMI)

แท็บ: บันทึก · ภาพรวม · รายชั้น · รายบุคคล

บันทึกน้ำหนัก/ส่วนสูง

  1. เลือกวันที่และชั้นเรียน
  2. กรอกน้ำหนัก (กก.) และส่วนสูง (ซม.) ของแต่ละคน
  3. ระบบคำนวณ BMI + แปลผลตามเกณฑ์ WHO (ตามเพศและอายุ) ให้อัตโนมัติ
💡 แปลผลเป็น ผอมมาก / ผอม / สมส่วน / น้ำหนักเกิน / อ้วน · แท็บ รายบุคคล มีกราฟแนวโน้ม BMI ตามเวลา
⚠️ นักเรียนที่ยังไม่มีวันเกิดในระบบ จะคำนวณแปลผลไม่ได้ — เติมวันเกิดได้ที่เมนูข้อมูลนักเรียน
🧑‍🎓 ข้อมูลนักเรียน

แท็บ: รายชื่อ · ภาพรวม

  1. ค้นหาด้วยชื่อ/รหัส หรือกรองตามชั้น
  2. แตะชื่อนักเรียนเพื่อดู โปรไฟล์รายบุคคล — รวมข้อมูลข้ามโมดูล: เงินฝาก, ทุนการศึกษา, BMI, คะแนนพฤติกรรม, สุขภาพ, การมาเรียน
  3. กด แก้ไขข้อมูล เพื่อปรับปรุงชื่อ/ชั้น/วันเกิด/ผู้ปกครอง ฯลฯ
⚙️ ตั้งค่าระบบ

แท็บ: ข้อมูลโรงเรียน · นำเข้า DMC · PIN · Backup/Restore · ระบบ

  • ข้อมูลโรงเรียน — ชื่อ, ปีการศึกษา, ภาคเรียน (ใช้ทั่วทั้งระบบ)
  • นำเข้า DMC — อัปโหลดไฟล์ Excel จาก DMC เพื่อสร้าง/อัปเดตทะเบียนนักเรียน
  • PIN — ตั้งรหัสสำหรับเมนูที่ต้องใช้ PIN
  • สำรอง / กู้คืน — ดาวน์โหลดไฟล์สำรองข้อมูล และกู้คืนได้
  • สร้าง Sheet ทั้งหมด — เตรียมฐานข้อมูลครั้งแรก (รันซ้ำได้ ไม่ลบข้อมูลเดิม)
⚠️ ไฟล์ DMC มีเลขบัตรประชาชนเด็ก — เก็บเป็นความลับ ห้ามเผยแพร่
