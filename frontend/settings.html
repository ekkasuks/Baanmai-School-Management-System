🏫 ข้อมูลโรงเรียน

📥 นำเข้าข้อมูลนักเรียนจาก DMC

วิธีใช้: เลือกไฟล์ Excel จาก DMC (.xlsx) — ระบบอ่านหัวคอลัมน์ภาษาไทยอัตโนมัติ แล้วนำเข้าทีละ 50 แถว · รหัสที่ซ้ำจะถูกอัปเดต
พบ 0 แถว  |  0 คอลัมน์

🔒 ตั้งค่า PIN

ธนาคารและตั้งค่าระบบใช้บัญชีบุคลากรแทน PIN แล้ว (ธนาคาร = ครูทุกคน · ตั้งค่า = ผู้ดูแลระบบ) — PIN ด้านล่างใช้สำรองในช่วงเปลี่ยนผ่านเท่านั้น และจะ ใช้ไม่ได้ เมื่อเปิด "บังคับเข้าสู่ระบบเมื่อบันทึก" ที่แท็บผู้ใช้

💾 สำรองข้อมูล (Backup)

ดาวน์โหลดข้อมูลทุก sheet เป็นไฟล์ JSON เก็บไว้ในเครื่อง

♻️ กู้คืนข้อมูล (Restore)

คำเตือน: การกู้คืนจะเขียนทับข้อมูลปัจจุบันทั้งหมด ควรสำรองก่อนเสมอ

🎓 เลื่อนชั้นนักเรียน (สิ้นปีการศึกษา)

⚠️ สำคัญ: คำสั่งนี้จะเลื่อนชั้นนักเรียนทุกคนพร้อมกัน และเปลี่ยนปีการศึกษา ควรกด "สำรองข้อมูล" ก่อนทุกครั้ง (ทำได้ที่แท็บ 💾 สำรองข้อมูล) เผื่อต้องย้อนกลับ
  • อ.2→อ.3→ป.1→…→ป.6 (เลื่อนขึ้น 1 ชั้น)
  • ป.6 → จบการศึกษา (เอาออกจากรายชื่อ แต่เก็บประวัติไว้)
  • ปีการศึกษา +1 อัตโนมัติ · ห้อง/ข้อมูลอื่นคงเดิม
